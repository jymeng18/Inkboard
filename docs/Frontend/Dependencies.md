# Purpose of each NPM packages (ok not each)

@fontsource/* - just for fonts that are imported in src/index.css

@signalr - websocket connections

@tanstack/react-query - better ui fluidity, serve cached data, no useEffect() needed in general

axios - replacement for fetch(), I just like it for its interceptors

@use-gesture/react - makes mouse interactions( dragging, pinching, scroll, swipe) super easy to bind to react comp (canvas interactions smoother)

jotai - global and shared state management

konva - core of the entire app, canvas building

lucide-react - icon lib

motion - super smooth animations, (brush strokes be smoother)

perfect-freehand - super smooth canvas/svg drawings

sonner - notifications ( party invites, user joins party, etc. )

zod - allow runtime data validation (mainly to ensure my backend apis return proper data)

zustand - global state management ( might not use if we use jotai  )
